# Frisbee Flashcards

Flashcard-game om de regels van **indoor ultimate frisbee** (zoals gespeeld in Nederland) te leren.

Open `index.html` in je browser. Er zijn twee stapels:

- **Wanneer call je?**: een spelsituatie, en jij kiest de juiste call.
- **Indoor-regels**: 5 spelers, stall tot 8, herstart-tellingen, spirit of the game.

Twee modi: **Leren** (kaart omdraaien, "Wist ik / Nog niet") en **Quiz** (meerkeuze).
Kaarten die je nog niet kent komen vaker terug. Je voortgang wordt in je browser bewaard.

## Bronnen

- WFDF Rules of Ultimate 2025–2028 + Appendix v2.0 en Hand Signals: https://rules.wfdf.sport/resources/
- EUF Indoor Rules Appendix (indoor-aanpassingen): https://www.ultimatefederation.eu/rules-of-ultimate
- Controleer voor de Nederlandse competitie altijd het actuele reglement van Frisbee Nederland.

Gebaren zitten bewust niet in de game: er was geen betrouwbare, consistente set plaatjes beschikbaar.
Gebruik daarvoor het officiële WFDF-plaatjesblad: https://rules.wfdf.sport/wp-content/uploads/2025/03/WFDF-Rules-of-Ultimate-2025-2028-Hand-Signals-1-page.pdf
